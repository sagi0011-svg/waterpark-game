# ערכת הנושא "פיקסל" — הפעלה, כיבוי, וחזרה למקור

ערכת הנושא הופכת את `index.html` לסגנון פיקסל ארט 16 ביט,
בלי לגעת בלוגיקת המשחק ובלי לשנות אף אלמנט HTML.

## הקבצים

| קובץ | תפקיד |
|---|---|
| `splash/theme-pixel.css` | כל העיצוב. תחום כולו תחת `html[data-theme="pixel"]` |
| `splash/theme-pixel.js` | המתג + הזרקת סצנת הפארק כרקע |
| `index.html` שורות 11-12 | שתי שורות שטוענות את שניהם |

## איפה השחקן בוחר

**מסך הפתיחה** — מתחת לכפתורי המשחק, תחת הכותרת "סגנון תצוגה":

```
   👾 רטרו        ✨ חדשני
```

**בתוך המשחק** — תפריט ☰, שורה בשם "סגנון תצוגה". ההחלפה מיידית,
ההתקדמות נשמרת.

ברירת המחדל לשחקן חדש היא **רטרו**. הבחירה נשמרת ב-localStorage
ומחזיקה בין משחקים.

### מה משתנה בין השניים במסך הפתיחה

| | רטרו | חדשני |
|---|---|---|
| רקע | סצנת הפיקסל, אטימות מלאה | ה-SVG המקורי |
| כותרת | קרם עם מתאר כהה מלא | לבן עם צל רך |
| כפתורים | מרובעים, צל קשיח | מעוגלים 22px |

ה-SVG וסצנת הפיקסל **לא** מוצגים ביחד. לפני התיקון הם היו — שני פארקי
מים אחד על השני, שניהם ב-z-index 0.

## החלפה מהירה

```
index.html?theme=classic    ← העיצוב המקורי
index.html?theme=pixel      ← פיקסל
```

הבחירה נשמרת ב-localStorage. אפשר גם מהקונסולה, בלי טעינה מחדש:

```js
splashTheme('classic')
splashTheme('pixel')
```

## חזרה לעיצוב המקורי — שלוש רמות

### 1. זמנית (שנייה אחת)
`index.html?theme=classic` — או `splashTheme('classic')` בקונסולה.

### 2. ברירת מחדל (שורה אחת)
ב-`splash/theme-pixel.js`, שורה 19:

```js
const DEFAULT = 'pixel';     // ← שנה ל-'classic'
```

מעכשיו המשחק עולה במראה המקורי, ופיקסל זמין ב-`?theme=pixel`.

### 3. ביטול מוחלט (מחיקת שתי שורות)

הבוחר נעלם מעצמו. `themePicker()` מחזיר `null` כשה-API לא קיים,
ושורת התפריט מוסרת — בלי מסגרת ריקה ובלי שגיאות.
ב-`index.html`, מחק את שורות 11-12:

```html
<link rel="stylesheet" href="splash/theme-pixel.css">
<script type="module" src="splash/theme-pixel.js"></script>
```

זהו. המשחק חוזר להיות בדיוק מה שהיה, ואפשר גם למחוק את תיקיית `splash/`.

## מה שונה ב-index.html עצמו

**כלום מבחינה ויזואלית.** שני שינויים בלבד, ושניהם שקופים:

1. **שתי שורות טעינה** (11-12).
2. **10 צבעים שהיו קשיחים בתוך ה-JS הוצאו למשתני CSS** — עם אותם ערכים
   בדיוק. למשל `#ede9fe` הפך ל-`var(--ruti-bub)`, ו-`--ruti-bub:#ede9fe`
   הוגדר ב-`:root`. המראה המקורי זהה לחלוטין; זה רק מאפשר לערכת נושא
   לדרוס אותם.

## החלטות עיצוב

- **רקע העמוד נשאר כהה.** גיליון הסגנון של המשחק מניח את זה — `.section-title`
  ו-`.small` צבועים בלבן כי הם יושבים על שמי התכלת. רקע בהיר הפך אותם
  לבלתי נראים (יחס ניגודיות 1.14).
- **טקסט כהה על כפתורים בהירים.** קרם על קורל נותן 2.24 בגודל 14px.
  דיו על קורל נותן 4.85. במסך הפתיחה הקרם דווקא עובד, כי שם המתאר עבה
  ביחס לגודל האות.
- **כרטיסי המותגים שומרים על זהותם.** וואטסאפ נשאר ירקרק, ביקורות גוגל
  צבעוניות, רותי סגולה. ההומור תלוי בזיהוי המיידי — הם קיבלו רק פינות
  מרובעות ומסגרות.
- **אימוג'י לא הוחלפו.** 131 אימוג'י ייחודיים משמשים כאייקונים. זה הדבר
  היחיד שנשאר לא-פיקסלי, והצעד הבא אם תרצה.

## מה נבדק

על מצב משחק אמיתי (חודש 5, 16 כרטיסי פיד מכל הסוגים):

| מסך | פינות מעוגלות | צללים רכים | נסיגות ניגודיות |
|---|---|---|---|
| דשבורד | 0 | 0 | 0 |
| בנייה | 0 | 0 | 0 |
| היסטוריה | 0 | 0 | 0 |

"נסיגה" = טקסט שקריא בעיצוב המקורי והפך ללא-קריא בפיקסל. נמדד בהשוואה
ישירה בין שתי ערכות הנושא על אותו מצב משחק בדיוק.

מעבר `pixel → classic → pixel` מחזיר את כל הערכים המקוריים, ומצב המשחק
(תור, כסף, פיד) שורד את שתי ההחלפות — גם מהבוחר במסך הפתיחה וגם מהתפריט.

נבדק גם מצב "שתי השורות נמחקו": מסך הפתיחה עולה במראה המקורי (רקע כחול,
פינות 22px, ה-SVG חוזר), הבוחר לא מופיע, שורת התפריט מוסרת, אפס שגיאות.
