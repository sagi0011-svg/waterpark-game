# ספלאש

סימולטור ניהול פארק מים ישראלי. פיקסל ארט 16 ביט, מובייל, עברית.
הסבב הזה מכיל **מסך בית + מנוע הרינדור** בלבד.

## הרצה

אין תלויות ואין שלב בנייה — הקוד הוא ES Modules שרצים ישירות בדפדפן:

```bash
python -m http.server 8766
```

ואז לפתוח `http://localhost:8766`.

כשיותקן Node אפשר לעבור ל-Vite בלי לשנות שום קובץ מקור:

```bash
npm install && npm run dev
```

## עקרון הליבה

כל המשחק מצויר לקנבס אחד ברזולוציה וירטואלית קבועה **180×390**,
ומועתק לתצוגה בהגדלה של **מספר שלם בלבד** (letterbox סביב).
כל קואורדינטה בקוד היא בפיקסלים וירטואליים.

ההגדלה מחושבת בפיקסלי מכשיר ולא ב-CSS pixels: על מסך `dpr=3`
מתקבל `S=6` במקום `S=2`, המשחק ממלא הרבה יותר מהמסך, והפיקסלים
נשארים חדים כי `S` עדיין שלם.

## מבנה

```
src/
  main.js            אתחול, לולאת רינדור (dirty flag), resize

  art/

    widgets.js       drawButton, drawFrame, drawPanel
```

## טקסט עברי

אין פונטי פיקסל טובים בעברית, ולכן לא משתמשים באחד: מציירים **Heebo**
רגיל ישירות לקנבס ה-180×390 בגדלים קטנים, וההגדלה השלמה היא זו
שהופכת אותו לפיקסלי.

- כל טקסט עובר דרך `drawText`. אין `fillText` ישיר בקוד המסכים.
- עברית ב-`dir: 'rtl'`; מספרים, `₪` ומחרוזות לטיניות ב-`dir: 'ltr'`
  בקריאה נפרדת — אחרת ה-BiDi הופך אותן.
- `ensureFonts()` מעביר טקסט לדוגמה ל-`document.fonts.load`, אחרת
  תת-הקבוצה העברית של Heebo פשוט לא נטענת.

## פרמטרים לפיתוח

- `?save=1` — מדמה משחק שמור (מציג את "המשך משחק")
- `?save=0` — מתעלם מהשמירה האמיתית
- `window.__splash` — זמין ב-localhost בלבד: `renderer`, `scene`, `redraw()`

# ערכת הנושא "פיקסל" על המשחק הקיים

`index.html` שבשורש הפרויקט הוא המשחק המלא. שני קבצים כאן מלבישים עליו
את השפה הוויזואלית של מסך הפתיחה, **בלי לגעת בלוגיקת המשחק**:

| קובץ | תפקיד |
|---|---|
| `theme-pixel.css` | כל העיצוב. כל הכללים תחומים תחת `html[data-theme="pixel"]` |
| `theme-pixel.js` | מתג ההפעלה + הזרקת סצנת הפארק כרקע |

החיבור למשחק הוא **שתי שורות** ב-`index.html`, מיד אחרי תגית `<title>`,
מסומנות בהערה בולטת.

## החלפה בין שני העיצובים

### הדרך המהירה — פרמטר בכתובת

```
http://localhost:8765/index.html?theme=classic
```

חוזר לעיצוב המקורי לחלוטין. הבחירה **נשמרת** ב-localStorage, כך שגם
בכניסות הבאות בלי הפרמטר המשחק יעלה במראה המקורי. לחזרה לפיקסל:

```
http://localhost:8765/index.html?theme=pixel
```

### מהקונסולה — בלי טעינה מחדש

```js
splashTheme('classic')   // חזרה למקורי, מיידית
splashTheme('pixel')     // חזרה לפיקסל
```

### שינוי ברירת המחדל

ב-`theme-pixel.js`, שורה 21:

```js
const DEFAULT = 'pixel';     // ← שנה ל-'classic'
```

כך המשחק יעלה במראה המקורי לכל מי שלא בחר אחרת.

## ביטול מוחלט

מחק את שתי השורות המסומנות ב-`index.html`:

```html
<link rel="stylesheet" href="splash/theme-pixel.css">
<script type="module" src="splash/theme-pixel.js"></script>
```

זהו. המשחק חוזר בדיוק למה שהיה, בלי שריד.

## מה כן שונה בקוד המשחק

מעבר לשתי השורות, נגעתי במקום אחד נוסף: **10 צבעים שהיו כתובים קשיח בתוך
ה-JS** (בועות של רותי, כוכבי ביקורות, סרגלי מצב־רוח) הוצאו למשתני CSS
ב-`:root`, עם **בדיוק אותם ערכים**. זה מה שמאפשר לערכת נושא לדרוס אותם.

המשתנים שנוספו: `--stars-good`, `--mood-hi1/hi2`, `--mood-mid1/mid2`,
`--mood-low1/low2`, `--heat-g1/g2`, `--ruti-calm1/calm2`, `--ruti-bub`, `--ruti-nm`.

השינוי הזה **לא משנה את המראה המקורי** — נמדד ואומת. אם תמחק את שתי השורות,
המשחק ייראה זהה למה שהיה לפני. אין צורך להחזיר אותו.

## השוואה זה לצד זה

```bash
python -m http.server 8765
```

ואז `http://localhost:8765/splash/theme-preview.html` — שני iframes של המשחק
האמיתי, לפני ואחרי.
